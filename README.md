# 行程卡手机版部署指南（Gitee Pages 已停服 → 改用腾讯云托管）

> ⚠️ 2026 年起 Gitee Pages 服务已停止，本指南已更新为两个可用方案：
> **方案 A：腾讯云托管**（Gitee 仓库菜单里直接有入口，最顺）
> **方案 B：EdgeOne Pages**（腾讯云旗下，免费额度大、国内加速好，拖 zip 上传）

两个方案部署成功后都会得到一个网页链接，微信发链接点开即看；
iPhone Safari 打开后「分享 → 添加到主屏幕」，桌面就有"行程卡"图标，像 App 一样。

---

## 方案 A：腾讯云托管（CloudBase 静态网站托管）

1. 打开 Gitee 仓库 https://gitee.com/lee_oops/travel
2. 顶部「服务」→「**腾讯云托管**」
3. 按提示**微信扫码登录/注册腾讯云**，并完成**实名认证**
4. 授权 Gitee 后，选择「**静态网站托管**」，部署目录选**根目录**，分支选 `master`
5. 点部署，等待完成，会得到一个形如 `xxx.tcloudbaseapp.com`（或自定义）的访问链接
6. 手机浏览器打开验证：能看到行程卡、能点晴/雨切换 = 成功

> 静态托管有免费额度（存储 1GB 级别、每月几 GB 流量，以控制台显示为准），
> 这个 30KB 的行程卡页面用到的额度可以忽略不计。

## 方案 B：EdgeOne Pages（拖 zip 上传，最省事）

1. 打开 https://pages.edgeone.ai （用腾讯云账号登录，微信扫码即可，需实名）
2. 「新建项目」→ 选择「上传压缩包」方式
3. 把本文件夹里的 `网页版部署包.zip` 拖进去（里面就是 index.html）
4. 点部署，得到一个 `xxx.edgeone.app`（或自定义）链接
5. 手机打开验证晴/雨切换

> EdgeOne Pages 免费版额度非常宽裕，且走腾讯 CDN，国内访问速度好。

## 手机端使用技巧

- **发微信**：把链接发给家人，点开即看
- **iPhone 桌面图标**：Safari 打开 → 分享 → 添加到主屏幕 → 命名"行程卡"

## 以后更新行程

1. 电脑上改主文件 `赤壁-广州惠州-3天2晚行程卡-PC版.html`
2. 让 AI 助手重新导出手机版 PDF，并把最新内容同步成 `index.html`（覆盖本文件夹里的旧文件）
3. 到部署平台重新上传/重新部署（腾讯云托管可绑定 Gitee 仓库后一键更新）
4. 手机刷新链接即可，链接不变、桌面图标不用重加
